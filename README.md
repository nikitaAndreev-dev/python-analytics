# Python Analytics

Учебные проекты по анализу данных: pandas, requests, визуализация.

## Стек
- Python 3.14
- pandas 3.0
- requests
- matplotlib

## Проекты

### 📊 pandas.ipynb
Работа с табличными данными:
- Создание и загрузка DataFrame из CSV
- Фильтрация, сортировка, группировка
- Очистка данных и работа с пропусками (NaN)
- Применение функций через apply()

### 🌐 Запросы к API
- GET-запросы через requests
- Разбор JSON-ответов
- Пагинация — сбор данных с нескольких страниц
- Сохранение результатов в CSV

### 📈 Визуализация
- График прогноза температуры в Перми
- Данные получены в реальном времени через wttr.in API

## Данные
- `posts.csv` — 30 постов с jsonplaceholder API
- `сотрудники_clean.csv` — очищенный датасет сотрудников
- `weather_chart.png` — график температуры
